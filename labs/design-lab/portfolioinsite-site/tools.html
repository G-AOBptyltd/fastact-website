How they fit together

Start with one. Add the others when it helps.

There's no lock-in and no forced order. Each tool stands alone, and because they share a model and a file format, moving between them is a JSON file — not a migration.

Export and JSON restore

Every tool writes a self-describing JSON backup you can restore later — or hand to another tool in the family. Your work is portable by default.

One shared governance model

Scoring, health and investment mix mean the same thing across the toolkit — so a forecast, a plan and a portfolio view all reinforce the same story.

Grow at your pace

Trial a single tool, prove the value, then bring in the rest of the suite — and step up to the PortfolioInSite Forge app when governance moves into Jira.

Your data, your machine

The tools run in your browser.

Each web tool works client-side — your backlog, velocity and portfolio data stay with you as a file you own. Nothing to provision, nothing to keep in sync by hand.
